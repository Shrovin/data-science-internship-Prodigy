# Data Science Internship Projects — Prodigy InfoTech

Four data science tasks completed as part of the Prodigy InfoTech Data Science internship, covering data cleaning, exploratory data analysis, visualization, and classification.

## 01. Population Data Analysis
Cleaned and analyzed world population data, identifying the top and bottom 10 countries by total population. Compared male vs. female population distributions between 2012 and 2022 using bar and stacked bar charts.

**Tools:** Python, Pandas, Matplotlib, Seaborn

## 02. Titanic EDA
Performed data cleaning (handling missing values in Age, Cabin, and Embarked; removing duplicates) and exploratory analysis on the Titanic dataset. Explored survival patterns by age and gender.

**Tools:** Python, Pandas, Matplotlib, Seaborn

## 03. Bank Marketing — Decision Tree Classifier
Built a Decision Tree Classifier to predict whether a customer subscribes to a term deposit, using the UCI Bank Marketing dataset. Compared Gini and Entropy split criteria.

**Result:** ~93% test accuracy

**Tools:** Python, Pandas, Scikit-learn

## 04. Twitter Sentiment Analysis
Preprocessed tweet data (tokenization, stemming/lemmatization) and explored sentiment and platform distributions. Extracted word frequencies and visualized results with word clouds and heatmaps; vectorized text using CountVectorizer.

**Tools:** Python, Pandas, NLTK, Scikit-learn, WordCloud
